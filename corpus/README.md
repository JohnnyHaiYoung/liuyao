# 资料处理区

开发阶段从 `F:\道教\六爻` 导入资料。本目录将同时保存原件副本、提取文本、清洗文本、元数据和质量记录，整体随 Agent 打包到服务器。文件处理流程见 [实施计划](../docs/implementation_plan.md)。

- `originals/`：保持目录结构的原始文件副本；服务器核对出处时使用。
- `extracted/`：尽量忠实于原文件的机器提取文本，带页码或段落定位。
- `cleaned/`：统一 UTF-8 的 Markdown，保留回到原件的定位标记。
- `assets/`：Markdown 引用的卦象、表格和必要图片；随发布包一起复制。
- `reports/`：转换失败、OCR 与人工抽查记录。
- `manifest.jsonl`：待转换程序建立；记录输入、哈希、输出和质量状态。

运行时只使用本项目内的相对路径，不访问开发机的 F 盘。清洗文本不会自动成为 Wiki 结论。
