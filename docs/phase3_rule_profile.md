# 第三阶段规则口径（人读版）

版本：`liuyao-rule-profile.v1`（机器可读副本见 [paipan/rules/rule-profile.v1.json](../paipan/rules/rule-profile.v1.json)）。本文件回答任务书第 3、7.2 节：字段定义、来源定位、默认选择、与上游差异、未核实点。

**证据等级**（不得混为一谈）：
- `原书原页核对`：阶段 2 包内原件原页印刷内容，已人工目视核对；
- `独立实现对照`：不同作者/不同语言的第二实现一致；
- `领域规则推导`：通行规则（京房纳甲等），本次由两套上游实现一致印证，但未逐条追溯古籍版本；
- `仅上游自测一致`：只有单一上游来源；
- `未核实`。

## 3. 默认选择与理由

1. **日界默认 `zi23`**：六爻以子时起于 23:00 为通行；盘面记录所用口径，可切换但不可中途改。
2. **月建按节气交接时刻**（非按天）：实测按天口径在该日 00:30 就提前换月（早于交接 19 小时）。
3. **缺日柱/月建一律 `null` + 原因**，不出"看似完整的默认盘"（两家上游中一家会静默降级，本项目不采用）。
4. **首版不实现随机/硬币起卦**：两家上游硬币约定相反（三背 9 vs 三背 6），且随机不可复现。
5. **生产只用 Node**：`lunar-typescript@1.8.6`（MIT、零传递依赖）；Python 侧仅开发期对照。
