## 本轮得到的设计修正

1. **起卦与解读方法先分轨。** 试点资料自身就把梅花易数和摇卦六爻分开讨论；知识库必须保存方法标签，不能把同名“卦”视作可互换的输入。
2. **文本可读性与可信度分开。** 转帖、摘录、讲义和无署名短文都可检索，但在没有核准出处前只列为候选观点。第三方 Skill 中的规则也采用相同标准。
3. **排除绝对化的现实断言。** 对疾病、婚姻、法律与财务等问题，术数文本可以作为研究对象；Agent 的最终结果不能把这类断语呈现成已经证实的现实事实。
4. **先做来源登记，再拆规则。** 下一步为每份试点文本记录作品名、疑似作者、版本、章节点与提取质量；能定位原文的规则才进入对照表。
